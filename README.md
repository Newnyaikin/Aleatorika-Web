# Алеаторика — Web 1.0

Самостоятельный веб-репозиторий. Статический сайт/PWA, без сборщика, npm-зависимостей и сервера приложений.

**Начните с [пошаговой инструкции](docs/START.md).**

Рекомендуемое имя репозитория: **aleatorika-web**, ветка **main**. Файл `index.html` находится прямо в корне репозитория.

## Автоматизация

- Push в `main`: проверка JavaScript и ресурсов, затем публикация GitHub Pages.
- Первый раз нужно включить **Settings → Pages → Source → GitHub Actions**.
- Pull request: только проверка, без публикации сайта.
- **Actions → Web - check and publish site → Run workflow**: ручная повторная публикация.
- Push тега `v*`: отдельный GitHub Release с ZIP веб-версии и ZIP исходников.

Сайт будет доступен по `https://YOUR_LOGIN.github.io/aleatorika-web/`. Точный URL показывает успешное задание deploy.

## Локальный просмотр

Из корня этого репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Не открывайте сайт двойным кликом по HTML для полноценной проверки микрофона/PWA. На телефоне нужен HTTPS; HTTP-адрес компьютера в локальной сети обычно не подходит.

Опциональная подготовка сайта как в CI: `python tools/prepare_site.py` (нужны Python 3 и Node.js 22+). Готовые публичные файлы попадут в `_site/`. На GitHub нужные программы устанавливаются автоматически.

## Важно

- Публикуйте весь проект, включая скрытую `.github/`; для готового хостинга можно использовать ZIP из Releases.
- Сайт работает в подпапке GitHub Pages: относительные пути, manifest и service worker сохранены.
- GitHub Pages не запускает Android-сборку. Android публикуется в другом репозитории.
- После обновления закройте старые вкладки/PWA и откройте снова: service worker может ещё обслуживать открытую старую версию.
- Микрофон требует разрешения сайта. Аудио обрабатывается локально.
- Версия 1.0 сохранена. Шрифт Manrope локальный, лицензия `fonts/OFL-Manrope.txt`.
- Репозиторий не включает приватных ключей, токенов или серверных секретов.
