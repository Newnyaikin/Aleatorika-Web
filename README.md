**Алеаторика** — приложение для развития музыкального слуха и практики на гитаре. Слушай ноты и аккорды, находи их на грифе или повторяй по схеме. Заниматься можно с гитарой и без неё.

## Возможности

- **На звук** — слушай образец и повторяй его на гитаре. В обучении можно продолжить и без проверки через микрофон.
- **По схеме** — смотри на ноту или аппликатуру и играй. Для аккордов доступны открытые формы, формы с баррэ или все вместе.
- **Без гитары** — находи услышанную ноту на интерактивном грифе или узнавай аккорд по рисунку. Микрофон не нужен.
- **Свой темп или игра на скорость** — выбирай обучение без таймера или тренировку на время с комбо и личными рекордами.
- **Удобные настройки** — светлая и тёмная темы, выбор диезов или бемолей и диапазона ладов в режиме грифа.
- **Установка как приложение** — поддерживаемый браузер может добавить Алеаторику на главный экран или установить её как PWA.

## Как начать

1. Открой **[Алеаторику в браузере](https://newnyaikin.github.io/Aleatorika-Web/)**.
2. Выбери режим: **На звук**, **По схеме** или **Без гитары**.
3. Выбери **ноты или аккорды**, а затем обучение или игру на скорость.
4. Если играешь с проверкой через микрофон, разреши браузеру доступ к нему. Наушники помогут уменьшить влияние звука образца на распознавание.
5. Нажми **«Начать»** и занимайся в удобном темпе.

> [!NOTE]
> Распознавание аккордов находится в стадии бета-тестирования и может ошибаться. Проверяется звучание аккорда, а не положение пальцев. Аудио обрабатывается на устройстве и не отправляется на сервер.

## Частые вопросы

**Можно ли пользоваться без гитары?**  
Да. В режиме **«Без гитары»** задания выполняются на экране — без инструмента и микрофона.

**Зачем нужен микрофон?**  
Он позволяет проверять игру на гитаре в соответствующих режимах. Браузеру нужно разрешение на доступ, а сайту — HTTPS или `localhost`. В обучении на звук можно продолжить и без автоматической проверки.

**Можно ли пользоваться без интернета?**  
После первого посещения приложение сохраняет ресурсы на устройстве для офлайн-доступа. Доступность зависит от браузера и того, сохранил ли он кеш.

**Где сохраняются настройки и рекорды?**  
В браузере на этом устройстве. При очистке данных сайта они могут удалиться; между разными браузерами и устройствами автоматически не синхронизируются.

**Как получить новую версию сайта?**  
Закрой старые вкладки и установленное приложение, затем открой сайт снова: предыдущая открытая версия может использовать сохранённый кеш.

## Для разработчиков

Веб-версия — статический сайт без сборщика и npm-зависимостей. Для локального просмотра из корня проекта запусти:

```bash
python -m http.server 8000
```

Открой [http://localhost:8000](http://localhost:8000). Для проверки файлов и подготовки сайта, как в GitHub Actions, нужны Python 3 и Node.js 22 или новее:

```bash
python tools/prepare_site.py
```

Готовые файлы появятся в `_site/`. Публикация из ветки `main` настроена через GitHub Actions; при первом запуске в **Settings → Pages → Source** нужно выбрать **GitHub Actions**. Подробнее — в [пошаговой инструкции](docs/START.md).
